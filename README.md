# kaigo_handoff_demo

介護施設向け。申し送り（隙間メモの積み上げ）と面談記録（会話→引用つき経過）。

**リポジトリ:** https://github.com/ideal-tomy/kaigo_handoff_demo

## セットアップ

```bash
cd kaigo_handoff_demo
npm install
npm run dev
```

## ルート

| パス | 内容 |
|------|------|
| `/` | 申し送り / 面談記録 |
| `/memo` | 10:00 → 12:30 → 16:45 の枠を順にタップ |
| `/karte` | 利用者選択 → 同意 → 録音 → 記録 |
