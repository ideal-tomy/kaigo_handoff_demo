# kaigo_handoff_demo

介護施設向け。隙間メモの積み上げによる申し送りと、会話の面談記録。

**リポジトリ:** https://github.com/ideal-tomy/kaigo_handoff_demo

## セットアップ

```bash
cd kaigo_handoff_demo
npm install
npm run dev
```

## ルート

| パス | 内容 |
|------|------|
| `/` | 申し送り。10:00 / 12:30 / 16:45 を順に録音 → 提出 |
| `/karte` | 面談記録。同意 → 録音 → 記録する |
| `/memo` | `/` と同じ |
