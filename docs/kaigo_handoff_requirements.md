# 介護施設 記録 — テーマ別要件定義書

## 背景

介護施設では、ケア中に「後で書こう」と思いながら本業を続け、終業後に記憶頼りで申し送り・経過記録を書く。面談では本人の言葉がスタッフ要約だけになりがち。

## 課題

- メモを取るタイミングがない
- 1日の断片が終業時に一括転記される
- 面談の本人発話が記録に残りにくい

## デモの目的

説明なしの操作面だけで、次を体験してもらう。

1. **申し送り（/memo）:** 10:00 / 12:30 / 16:45 の録音枠を順に押すと、4名分の下書きが積もり、終業前に提出できる
2. **面談記録（/karte）:** 同意 → 録音 → 本人の言葉（引用）→ 記録

## ルート

| パス | 内容 |
|------|------|
| `/` | 申し送り（入口）。時刻枠と録音、帳票 |
| `/karte` | 面談記録（ヘッダから。会話録音） |
| `/memo` | `/` と同じ |

## UI方針

- 説明文・サンプル表示・デモ表記・ステータスチップ・プレースホルダ・Before/After なし
- 残す文言: 書類名、欄名、時刻、人名、録音 / 停止 / 提出 / 記録する / 録音の同意
- サンプルは「時刻枠タップ」＝実操作と同じ見た目

## シナリオ（/memo）

- 担当: 日勤（暗黙）
- 利用者: 203田中 / 105山田 / 208鈴木 / 112佐藤
- クリップ3本。3本目後に田中・投薬欄のみ要修正 → 提出

## シナリオ（/karte）

- 203田中: 左膝疼痛の訴え
- 208鈴木: 食事拒否・味の嗜好
