# 介護施設 記録 — テーマ別要件定義書

## 背景

介護施設では、ケア中に「後で書こう」と思いながら本業を続け、終業後に記憶頼りで申し送り・経過記録を書く。面談では本人の言葉がスタッフ要約だけになりがち。

## 課題

- メモを取るタイミングがない
- 1日の断片が終業時に一括転記される
- 面談の本人発話が記録に残りにくい

## デモの目的

説明なしの操作面だけで、次を体験してもらう。

1. **申し送り（/memo）:** 10:00 / 12:30 / 16:45 を **録音** または **入力** で口語が報告書へ清書され、4名分の下書きが積もり、終業前に提出できる。提出後は **印刷** 可
2. **面談記録（/karte）:** **録音**（同意 → REC・波形・字幕）または **入力**（要約文）→ 空の経過記録が欄ごとに埋まる → 確認 → 記録。記録後は **印刷** 可
3. **日報（/nippo）:** 提出・記録された帳票を **確認** すると日報欄が埋まる。**録音** で空欄の利用者だけフロア一巡の摘要が入る。確認待ち件数を左に表示。個別帳票・日報とも **印刷** 可

## ルート

| パス | 内容 |
|------|------|
| `/` | 申し送り（入口）。時刻枠と録音・入力、帳票 |
| `/karte` | 面談記録。録音または入力のあと経過記録が自動で埋まる |
| `/nippo` | 日報。確認待ちを確認する。録音で空欄を埋める |
| `/records` | `/nippo` と同じ |

## UI方針

- 説明文・サンプル表示・デモ表記・ステータスチップ・プレースホルダ・Before/After なし
- 残す文言: 書類名、欄名、時刻、人名、録音 / 入力 / 停止 / 提出 / 記録する / 録音の同意 / 日報 / 確認 / 確認済 / 印刷
- サンプルは「時刻枠タップ」＝実操作と同じ見た目
